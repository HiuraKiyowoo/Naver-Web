## A. TINGGI — Hard Gate (harus dibenerin)

### A-01 · Favicon 404 di SETIAP halaman — R-24
- **Fakta:** `base.html` baris 18 minta `/static/ikon.svg`, tapi file itu **tidak ada** di `static/` (cuma `web.css` + `web.js`). Diverifikasi: `curl /static/ikon.svg → 404`.
- **Kenapa salah:** janji tautan mati; tiap halaman memicu 404 + tidak ada ikon di tab browser.
- **Usul:** bikin `static/ikon.svg` (huruf "N" cyan #049DFD di bg gelap, 32×32) ATAU hapus baris favicon. Pilih bikin — biar tab rapi.

### A-02 · Tap target < 44px — R-03
- **Fakta:** `.tombol` padding `11px 22px` + font 15px → tinggi ≈ 41px. `.nav-atas a` tinggi teks 14px tanpa padding. `.lebih` (tombol Selengkapnya) cuma `padding:8px 0`. `.halaman a` = `8px 14px` → ≈ 37px. Tidak ada satu pun `min-height:44px` di web.css.
- **Kenapa salah:** di HP susah dipencet (aturan minimum 44px).
- **Usul:** tambah `min-height:44px; display:inline-flex; align-items:center` ke `.tombol`, `.halaman a`, `.chip`, `.lebih`, dan nav atas.

### A-03 · Tidak ada `:focus-visible` — R-32
- **Fakta:** `grep focus-visible web.css → 0`. Yang ada cuma `input:focus`/`select:focus` (ganti border). Link/kartu/tombol tidak punya penanda fokus yang kelihatan, dan tidak ada `outline` yang diganti.
- **Kenapa salah:** pengguna keyboard tidak tahu sedang di mana.
- **Usul:** tambah `a:focus-visible,button:focus-visible,input:focus-visible,select:focus-visible{outline:2px solid var(--cyan);outline-offset:2px;border-radius:6px}`.

### A-04 · Em dash (—) di teks UI — R-02
- **Fakta:** 6 tempat di teks yang terbaca pengguna:
  - `base.html:44` → `{{ nama }} — arsip pribadi novel terjemahan.`
  - `beranda.html:2` → `{{ nama }} — Baca Novel Terjemahan Indonesia`
  - `cari.html:26` → `{{ h.novel_judul }} — {{ h.judul }}`
  - `apk.html:8` → `...langsung dari HP — lebih ringan, ada unduhan bab.`
  - (`main.py` judul/desk juga pakai `—`; `main.py:174/244/265/294` dll.)
- **Kenapa salah:** R-02 melarang em dash di teks yang ditulis agen; bikin terasa mesin.
- **Usul:** ganti jadi koma / titik dua / tanda kurung. Contoh: `Naver Novel: arsip pribadi...`, `Cari: {q}`.

### A-05 · Tidak ada state loading & error — R-27
- **Fakta:** cuma ada empty state ("Tidak ada hasil...", "Belum ada novel..."). Tidak ada loading (situs SSR penuh → tidak terlalu perlu) dan **tidak ada halaman error 404/500 sendiri** (`raise HTTPException(404)` → JSON `{"detail":"Not Found"}`, bukan halaman HTML bertema).
- **Kenapa salah:** R-27 minta 3 state; error JSON mentah di situs HTML itu jelek + bingung.
- **Usul:** tambah handler 404/500 → template `galat.html` (judul, pesan, tombol kembali + cari). Loading cukup karena SSR.

### A-06 · Emoji & lambang sebagai hiasan — R-31 / antislop-ui (Emoji as Decoration)
- **Fakta:** `_kartu.html:9` `★`, `novel.html:14` `★`, `novel.html:58` `🖼️`, `bab.html:38/40` `‹ ›`, `beranda.html` `→` di 4 tautan "Lihat semua".
- **Kenapa salah:** emoji di UI = tanda paling keras "buatan mesin"; `→` di tiap tautan jadi hissan, bukan sinyal.
- **Usul:** `★` ganti "Rating 8.5" (teks) atau SVG bintang; `🖼️` ganti label "Bergambar" kecil; `→` simpan HANYA di tautan "Lihat semua" (memang arah) dan buang dari yang lain; `‹ ›` di paginasi boleh (arah nyata) tapi ganti jadi "Sebelumnya/Berikutnya" di nav bab.

## B. SEDANG — Purpose-Gate (teknik boleh, alasan harus ditulis)

### B-01 · Gradient cyan dibanyak tempat tanpa alasan tertulis — R-01
- **Fakta:** `linear-gradient(135deg,var(--cyan),#0069c0)` di logo, tombol utama, tombol APK; plus radial cyan glow di hero (`.hero` radial-gradient rgba(4,157,253,.32)).
- **Kenapa salah:** gradient cyan = resep default "AI modern" kalau tak ada alasan. Namun di sini cyan = warna identitas APK (perintah user), jadi **boleh** — yang kurang cuma alasan tertulis.
- **Usul:** tulis 1 baris alasan di `DESIGN.md`/komentar CSS: "gradient cyan menandai tingkat aksi utama (CTA) + identitas APK". Kalau tidak mau ribet: rata-kan CTA jadi cyan solid, sisakan gradient di logo saja.

### B-02 · Glow radial di hero — R-13
- **Fakta:** `.hero` punya `radial-gradient(900px 400px at 12% -10%,rgba(4,157,253,.32),transparent 60%)`.
- **Kenapa salah:** glow harus fokus 1-2 elemen; ini glow latar (orb) yang justru pola default.
- **Usul:** buang glow-nya, ganti tekstur/gradien garis halus; atau kalau disimpan, tulis alasannya ("menarik mata ke judul hero").

### B-03 · Animasi tanpa pematokan dial — R-19
- **Fakta:** `transform` hover pada tombol (`translateY(-1px)`) dan zoom cover (`.kartu:hover img scale(1.05)` + `transition .25s`). Tidak ada `prefers-reduced-motion`.
- **Kenapa salah:** MOTION belum dipatok; dasar (draft tanpa arah) harus ENERGY 1 / RHYTHM 1 / MOTION 1 → animasi zoom mungkin berlebih.
- **Usul:** patok dial di DESIGN.md; tambah `@media(prefers-reduced-motion:reduce){*{transition:none!important;animation:none!important}}`.

### B-04 · Judul "Random Novel" & label samar — R-31
- **Fakta:** `beranda.html:62` `<span class="lebih redup">pilihan hari ini</span>` (pakai kelas `.lebih` yang warnanya cyan padahal ini bukan tautan); label "pilihan hari ini" tak menjelaskan apa pun.
- **Kenapa salah:** kelas `.lebih` dipakai untuk 2 maksud (tautan vs label mati) → bingung + alasan tak tertulis.
- **Usul:** ganti label jadi "Acak tiap hari" (sebab nyata), pakai kelas `.redup kecil` (bukan `.lebih`).

## C. RENDAH — Quality Lock

### C-01 · Radius nyaris seragam + pill di mana-mana — R-11
- **Fakta:** `border-radius:999px` di pencarian, tombol, chip, pil meta, lencana; `14px` di kartu; `10-12px` di item. Nyaris tak ada tangga radius yang jelas (hanya 6/9/10/12/14/20 + 999).
- **Usul:** patok tangga: 999 (pil aksi), 14 (kartu), 9 (isian kecil). Rapikan.

### C-02 · Ritme bagian seragam — R-05
- **Fakta:** beranda = 7 bagian, hampir semua bentuknya "judul kiri + tautan 'Lihat semua' kanan + rak geser/grid". Hero 1, chip 1, sisanya seragam.
- **Usul:** kalau RHYTHM 1 (draft), seragam itu boleh — tapi tulis "seragam sengaja" di DESIGN.md. Kalau mau hidup, buat 1 bagian unggulan beda bentuk (mis. Populer jadi 1 kartu besar + 3 kecil).

### C-03 · Alasan keputusan belum tertulis — R-31
- **Fakta:** tidak ada `DESIGN.md`/komentar alasan di CSS (cuma komentar "tema Naver: Bg #071018 ...").
- **Usul:** user tulis `DESIGN.md` (identitas, palet, huruf, mood, dial). Ini yang mengangkat web dari "draft tanpa arah" jadi hasil layak.

## D. Yang SUDAH BAGUS (jangan diutak-atik)

1. **Kontras WCAG AA LOLOS semua** (diukur, bukan dikira): teks 16,75:1 · redup 7,65:1 (bg) / 6,83:1 (kartu) · cyan 6,61:1 · tinta cyan 6,55:1 · isi bab 13,71:1. Satu-satunya di bawah: `#25455c` huruf besar "tanpa cover" 1,48:1 — **hiasan**, bukan teks isi, jadi aman (boleh naikkan jadi #3d6a86 kalau mau).
2. **Nav semua nyata** — tiap `href` punya halaman (diverifikasi 200): `/`, `/jelajah`, `/apk`, `/sitemap.xml`, `/status`.
3. **JSON-LD BENAR** — `"@context":"https://schema.org"` utuh (sempat tampak rusak di `cat`, ternyata aman → **alarm palsu, tidak ada bug**).
4. **Palet disiplin** — 22 kode warna tapi inti cuma 1 aksen (cyan) + netral; sesuai R-29.
5. **Struktur ikut konten, bukan template** — tak ada "Trusted By", testimoni karangan, statistik palsu, pricing 3 kolom, footer 4 kolom. Sesuai C-3/R-05.
6. **Tak ada data/klaim karangan** — R-17/R-18/R-36/C-5 lolos (angka asli dari `naver.db`).
7. **Mobile dasar jalan** — meta viewport ada, header wrap di ≤820px, rak geser `overflow-x:auto` (tidak ada overflow halaman), kartu `flex:0 0 138px`.
